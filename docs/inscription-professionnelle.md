# Inscription professionnelle et création d’entité — 25 novembre 2026
Page publique /professionnels-du-batiment/ ; POST /professionnels-du-batiment/inscription/. Activation désactivée par défaut (pro_signup_enabled=false). Une fois le PHP historique installé et testé, activer dans inc/config.php.
## Contrat serveur
Endpoint : https://espace-client.keeplanet.fr/pages/ajout-projet/traitement-inscription-pro-public.php. Fichier PHP 5.6/mysql_* fourni séparément à l'administrateur (ne pas publier ce traitement serveur dans le dépôt public). POST societe, prenom, nom, email, telephone facultatif, adresse, code_postal (5 chiffres), ville, origine=r-e-2020.fr, profil=professionnel, creation_entite=1. Marqueurs indicatifs uniquement.
Pour un nouveau compte, insertion clients.donnees (statut 0, type_demande vide, nom=entreprise, gerant=prénom nom) d'après le PHP maison fourni. Insertion contacts.entite : adresse, cp, ville, telephone, mail, nom=entreprise, num_gerant identique. Aucun pack ou devis fictif, pas de remise automatique. Vérifier que type_demande vide correspond bien au compte sans prestation dans le système historique et que le champ password accepte 16 caractères (le traitement refuse les accès tronqués). Le mail transmet les accès uniquement à l'adresse inscrite ; pas d'autoconnexion via URL. Pour une adresse existante (donnees, compte_vide, devis ou entite), aucun changement automatique ni rattachement : invitation à utiliser les accès habituels et contacter l'équipe.
## Recette avant activation
Vérifier permissions LOCK TABLES, SELECT/INSERT/DELETE, moteurs de tables, allocation historique de num_gerant et colonnes obligatoires/defaults de contacts.entite ; vérifier en test les deux écritures, le login, le mail, la non-création de doublon et le nettoyage en cas d'échec. Verrous et rollback/compensation prévus ; si moteurs non transactionnels, impossibilité de garantir l'atomicité en cas de crash serveur. Les autres scripts historiques MAX+1 doivent idéalement partager une allocation centralisée. L'adresse postale est demandée pour renseigner l'entité ; activité et SIRET retirés du formulaire car aucune colonne correspondante n'a été demandée. Aucun changement aux pages de conversion maison/devis.
