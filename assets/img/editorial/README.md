# Visuels éditoriaux RE2020
Images générées à titre illustratif, pas de photographies de salariés ni de clients réels. Les légendes publiques les identifient comme illustrations générées. Les visuels ne constituent pas des exemples de livrables réglementaires.
Format WebP, 1200 × 675 px, optimisé pour le web.
- accompagnement-maison.webp : accueil.
- thermicien-conseil.webp : accompagnement et contact (accueil, maison).
- etude-collectif.webp : collectif/tertiaire.
- plans-etude-thermique.webp : processus de réalisation.
Les images WebP peuvent être remplacées par des photographies réelles ultérieurement, avec mise à jour des textes alternatifs et légendes. Les quatre versions web sont également conservées dans le dossier Drive du projet.
